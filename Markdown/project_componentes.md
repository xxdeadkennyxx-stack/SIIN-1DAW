# 📐 Proyecto de Aprendizaje: Componentes de un Ordenador

---

## 🎯 ¿Qué voy a aprender?

- **QUÉ componentes tiene un PC**
- **PARA QUÉ sirve cada uno**
- **CÓMO se relacionan entre sí**

---

## 📊 Componentes: ¿Qué necesito estudiar?

| Componente | Nivel | Qué debo saber |
|---|---|---|
| **CPU**    |       🔴 Importante | Qué hace, velocidad, generaciones actuales |
| **RAM**    |       🔴 Importante | Cuánta necesito, DDR4 vs DDR5, velocidad |
| **Placa Base**   | 🟡 Normal | Qué conecta, compatibilidades básicas |
| **Conec/Cables** | 🟢 Reconocer | Identificar cuando sea necesario |

---

## ✍️ Cómo investigar cada componente

Para **cada componente** que estudies, busca esta información:

1. **¿Qué es?** (1-2 líneas explicando su función)
2. **¿Cuáles existen ahora?** (Generaciones/modelos 2024-2025)
3. **¿Qué números importan?** (GHz, GB, MB/s, W, etc.)
4. **¿Cómo se conecta?** (Con qué otros componentes trabaja)
5. **¿Cuándo importa?** (Gaming, ofimática, edición, etc.)

---

## 🔍 Dónde buscar información

- **Documentos y enlaces del profesor**
- **Datasheets**: Intel, AMD, NVIDIA, Samsung (en sus webs oficiales)
- **YouTube técnico**: Canales en español sobre hardware
- **Blogs**: TechPowerUp, Tom's Hardware
- **Comparativas recientes**: Busca de 2022-2026, no más viejas
